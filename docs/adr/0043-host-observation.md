# Host observation sits beside Authorship; Headless is no window

Machine-facing stills and Play stepping are **Host observation**, not a fourth Authorship intent. **Capture** is a 16:9 **Scene still** (Play-rule camera, no Editor Overlays, shared path with Scene Thumbnail Render, not the thumbnail cache, not HWND, not Camera Preview selection). **Play frame** is a still of the ticking Play Process world; **Play step** advances a paused Player by N ticks at dt 1/60 on the **Play control channel** (no second socket). Diagnostics stay **Console Messages**. **Headless** is Editor or Player with no OS window — not a third `EngineHostMode`; Headless Editor omits Slint/UiHost/viewport sink and still mounts Authorship System. Windowed Player close remains Stop; Headless Player ends via Stop or process exit. Rejected: Observe on the Authorship contract; Query of the Player; Capture as Play frame; scraping the OS window; a Host event bus beside Console; `EngineHostMode::Headless` or `engine_agent`; Play dump in v1; variable-dt or playing-state step.
