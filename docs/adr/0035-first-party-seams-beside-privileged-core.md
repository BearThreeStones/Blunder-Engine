# First-party seams beside a privileged core

Blunder keeps a **Privileged core** (ClassDB, C-ABI, RHI, Object–Entity binding) and **First-party composition** (statically linked engine code, not loadable plugins). Extensibility is **Seam registration** beside that core, not DeepSeek/Cordis “everything is a plugin.” The first Seam is the **SkeletonModifier type catalog**: a factory table keyed by ClassDB class names (factory + Add… visibility), not ClassDB instantiate and not a second property database. Unknown types load as a **Missing SkeletonModifier** (type name + opaque field bag, Save writes back). Rejected: third-party native plugin ABI, C# editor-script composition, an Editor Command type registry, growing ClassDB to own this Seam, coercing unknown modifiers to the base type, and moving Registered Systems / Host composition in the same slice. Import codec is the next Seam; Editor/Player System split stays directional until then.
