# Mesh Preview Render uses a dedicated offscreen (not Camera Preview / main viewport)

**Mesh Preview Render** draws a **Mesh Asset** (Final preferred, else Fast Path) with automatic AABB framing and fixed studio lighting into a **dedicated** offscreen render target, then CPU-readback feeds both **Content Browser Thumbnails** (async, visibility-prioritized cache writes) and interactive **Mesh Preview** in **Asset Inspector**. Rejected for this slice: reusing the **Camera Preview** secondary RT or the main viewport offscreen (different owners and lifecycles; ADR 0018 already rejected blit-into-main for PiP); using material base-color textures alone as Mesh thumbnails; forcing Cook before any 3D Mesh still; and splitting Thumbnail vs Inspector into two unrelated render stacks. HDRI/IBL studio lighting and Import-settings editing in Asset Inspector stay later.
