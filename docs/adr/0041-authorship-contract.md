# Authorship contract sits above Editor Commands

Machine authorship is a first-party **Authorship contract** (Query / Op / Diagnose), hosted by an editor-only **Authorship System** (Registered System, not a Seam, not Privileged core, not mounted in the Player). One Op commits exactly one Editor Command; Query and Diagnose do not push History. The public scene target is the scene-unique entity name already persisted on the Scene Asset (Asset identity remains GUID); EntityId stays Command-internal and ObjectId is not the v1 public address because it is not persisted on the scene. Diagnose returns **Issues** (stable code + Console-aligned severity); Play camera preflight is that Diagnose; Play Scripts build remains a mutating Play step whose failures map to Issues but is not Diagnose. Rejected: exposing Editor Commands as the machine catalog or as a Seam; EntityId or ObjectId on the contract; Diagnose as a Query projection; compiling inside Diagnose; a second mutation path that bypasses History; Play keeping a parallel stringly error beside Issue.
