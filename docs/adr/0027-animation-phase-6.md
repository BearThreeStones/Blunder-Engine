# DogWalk animation Phase 6: product SkeletonModifiers (PaperMouth, Attach, LookAt)

DogWalk still needs visible mouth / prop-attach / aim feel on top of the Phase 5 modifier **chain**, without opening leash, audio tracks, Tree canvas, or a cutscene director. We decided a **hybrid** milestone: a **thin engine seam** that productizes three ClassDB modifiers—**PaperMouth** (jaw `openAmount`, optional attach-driven fill of the same scalar), **SkeletonAttachModifier** (host bone → **child Object Transform**, not cross-Object Skeleton drive), and **LookAt** elevated from sample to configurable product—plus **scene serialization + Inspector** for those three, a **lean C-ABI / Blunder.Api bump** for key drives only, and **content Done** limited to Edit/Play feel of these modifiers. Phase 1–5 open content gates stay tracked separately. Explicitly out: leash, audio tracks, Cubic/Bezier, AnimationLibrary, Cutscene Director, Tree canvas-as-Done, generic C# SkeletonModifier subclass hot-bridge, remote Skeleton animation drive, closing older content Done via this phase alone, full Pinda parity as the sole bar.

**Considered options:** content-only Phase 6; fat engine dump of all Phase 5 deferrals; leash-in-scope; Attach as same-Object-only or full cross-Object Skeleton bind; PaperMouth as Godot-parity mouth; serialize-later / Behaviour-only assembly; full NativeAbi mirror of every Inspector field. Rejected for scope blow-up, glossary conflict with cross-Object Skeleton drive, or weak authoring reproducibility.
