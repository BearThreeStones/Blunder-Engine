# Clip Binding authorship: asset assign + logical name, not pasted GUID

Authors assemble AnimationPlayer **Clip Bindings** (logical name → AnimationClip Asset Reference) by Content Browser drop or an AnimationClip picker; the regular Inspector does not show or edit GUID. Drop is location-sensitive: empty list / Add clip appends; existing row retargets and keeps the logical name; miss does not mutate the map. Scripts and **Behaviour clip name** fields marked `[BehaviourClipName]` (catalog `kind: "clip_name"`) address bindings by logical name only (weak refs, dropdown over the co-located player map) — not by owning a second Asset Reference on the Behaviour. Import still does not auto-fill the map (ADR 0031). Rejected: Behaviour-owned clip object fields as the primary Play key, paste-GUID as the product fill, Import packaging auto-fill, cascading rename of Behaviour strings when a binding is renamed, treating every Behaviour string as a clip name, and rewriting AnimationTree/Sync clip UIs in the same slice.
