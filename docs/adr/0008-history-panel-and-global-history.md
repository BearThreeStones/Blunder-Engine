# History Panel uses dual stacks; Global History ships empty

Editor History gains a **History Panel** (sibling tab to Content Browser) that lists commands and supports **History Jump** via the same undo/redo APIs. Scene edits remain on **Document History**. A separate **Global History** stack is introduced for future non-document actions (preferences, layout), but this milestone ships it as an **empty placeholder** with Scene/Global filters (default both on; both on still shows only Scene—no merge). Shortcuts and Edit menu stay bound to Document History only. Command labels are English action+snapshotted entity name. This does **not** overturn ADR 0006’s rejection of a cross-scene undo continuum: Global is a parallel stack for non-document work, not a merged timeline of scene edits. Rejected alternatives: panel-only visualization without a Global stack concept; merging Scene/Global into one stack; focus-based shortcut routing before Global Commands exist.
