# Scene thumbnails use a dedicated Scene Thumbnail Render offscreen

**Scene Thumbnail Render** produces **Content Browser Thumbnails** for on-disk **Scene Assets** by temporarily instantiating the scene, resolving a camera with the Play rule (Main, else first), and drawing one square-aspect still into a **dedicated** offscreen target with CPU readback into the thumbnail cache — not the main viewport, not **Camera Preview**, and not **Mesh Preview Render**. Rejected for this slice: first-mesh proxy or studio-only mesh composite as the product Scene thumb; reusing Camera Preview / main viewport RTs; sampling AnimationPlayer for thumbs; dirty live SceneInstance as the cache source; and authored cover images as a v1 requirement. Failure falls back to a Scene placeholder; cache keys include scene mtime plus direct Mesh Asset Reference fingerprints on that scene. *(Nested recursive childScenes for thumbs superseded by [ADR 0030](0030-remove-child-scenes.md).)*
