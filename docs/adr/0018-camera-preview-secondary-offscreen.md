# Camera Preview uses a dedicated secondary offscreen and second Slint image

**Camera Preview** renders the scene through a selected **Camera Component** into a dedicated secondary offscreen render target (longest edge ≤480, aspect from the panel content box, shadows off, no **Editor Overlays**), then CPU readback presents into a second Slint `image` inside a floating `CameraPreviewPanel` over the viewport tile. The panel blocks viewport pick and **Editor Camera** orbit under its rect; layout memory is in-process only. The editor-only panel never ships in the Player. Rejected for this slice: blitting the preview into the main `viewport-image` offscreen (would complicate zero-copy present and tie PiP to main RT lifecycle); OverlaySystem-only chrome without a second image (title bar, drag, resize, collapse, and Collapse menu require Slint UI, not Vulkan screen overlays alone); and a docked Game View or multi-camera simultaneous previews.
