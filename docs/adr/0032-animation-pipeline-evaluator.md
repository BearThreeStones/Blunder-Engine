# Animation Pipeline as first-class evaluator

DogWalk Phases 1–6 already sample clips, blend, run SkeletonModifiers, and skin meshes, but evaluation was folded into AnimationPlayer / AnimationTree and palette build lived in the render bridge. We decided to introduce a first-class **Animation Pipeline** per animated Object: stages extract → blend → Global Pose → SkeletonModifier post-process → global recompute → Matrix Palette, with **PoseApplied after stage 6**. **AnimationPlayer** remains the near-term **scheduler** (advance / active Tree sample call `Pipeline.evaluate`); Player and Tree are **blend-specification producers**, not the pipeline itself. **Local Pose** stays on **Skeleton**; **Global Pose** and **Matrix Palette** are explicit Pipeline buffers (Global in Skeleton/model space, no Object world TRS). Near-term: separate **Player** and **Tree** blend-specification shapes, one Pipeline for stages 3–6; unified BlendSpec algebra is a later aim. Modifiers: semantic read-Global / write-Local model, but first implementation always recomputes Global after the chain. Matrix Palette is computed on each evaluate by default (lazy skip only for non-visible / non-skinned); Skinning **consumes** that buffer. LookAt product **target** is world space, converted at modifier entry. **First slice:** extract evaluate + buffers + render bridge reads Pipeline palette — not unified Spec, not world-batch Animation System, not PreGlobal/PostGlobal chain split. Domain terms: [CONTEXT.md — Animation Pipeline](../../CONTEXT.md).

**Status:** accepted (decision + glossary first; code follows)

**Considered options:** Glossary-only alignment without an evaluate host (rejected — stages 3/5/6 stay implicit). Greenfield replace of Player/Tree (rejected — breaks Phase 1–6 surfaces). Skeleton as static reference only with fully separate pose buffers (rejected for first cut — Local stays on Skeleton). World-batch Animation System as first host (deferred). Single unified BlendSpec on day one (deferred — keep PlayerSpec / TreeSpec). Always-lazy palette only in the draw bridge (rejected as authoritative path). Baking Object world TRS into Global Pose (rejected — corrupts skinning). Splitting Modifier chain into PreGlobal/PostGlobal as first Done (deferred).
