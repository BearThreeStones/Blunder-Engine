# Directed Object Messages for cross-Object gameplay communication

Blunder adopts Harmon-style **directed Messages** (not Signals) for cross-Object gameplay notifications and commands: `Message.Send(ObjectId, MessageId, ??? args)` fans out synchronously to every Behaviour on the target in list order via a single `OnMessage` entry. MessageIds are game-registered names; the engine ships no Damage/Hit vocabulary. Queries and property reads stay on the Object property surface / sibling Behaviour access; Lifecycle Ready/Tick stay separate. MVP exposes Send only from C# through NativeAbi (same delivery path reserved for later native senders). Rejected for this slice: Godot Signal subscribe/emit as the primary primitive, Win32 raw int/pointer pairs, query Messages, broadcast/subtree addressing, Handled-stops-siblings, and requiring physics to Send in the MVP.
